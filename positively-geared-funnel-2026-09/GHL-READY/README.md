# GHL-ready code kit

Open **START-HERE.html** for a copy-and-paste installer. It includes all five pages, editable destination URLs, code copy buttons and native checkout placement. It works locally without a server.

This is a set of Custom HTML/JavaScript snippets. The ZIP is only a convenient delivery package to extract on your computer; it is not a HighLevel snapshot or an importable native funnel. HighLevel’s funnel import feature imports existing HighLevel pages and does not turn an arbitrary HTML file into a native drag-and-drop page. Text and layout inside these custom blocks are edited in code.

## What is included

- Only deployment snippets and installation instructions; no demo form or preview navigation in the page code.
- White and book-yellow backgrounds, responsive layouts, GitHub image URLs, embedded videos, media/award animation and accessible reduced-motion behaviour.
- Complete, scoped HTML/CSS/JavaScript fragments without outer html, head or body tags.
- Existing Calendly booking embed on the discovery page.
- Relative step links for portability; the installer can substitute your chosen paths or full HTTPS URLs.

## Remaining GHL setup

Attach products, prices and the payment provider; add three native order forms; set order-success redirects and fulfilment. Confirm the guide’s bump price before enabling it. The existing secondary video introductions still show the old two-book offer and need revision for the one-book campaign. No code in this package takes card payments, creates orders, submits contacts or books appointments by itself.

## Validation

Fragments checked for balanced container boundaries, scoped styles, script syntax, duplicate IDs, hosted image references, local-file references, and preview-only UI. Final account-specific rendering and test-mode purchases require the GHL builder and connected payment account.
